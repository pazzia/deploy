# CodeQuest MVP

Gamified mobile programming puzzle app — Python-first MVP.

MVP includes onboarding, learning map, 20 Python levels, multiple-choice/fill-missing/code-ordering puzzles, XP, stars, lives, streaks, local progress persistence and profile statistics.

## CI/CD

Every push to `master` runs Flutter analyze/tests, builds a release APK and publishes it as a GitHub Release.
